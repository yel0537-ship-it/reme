# Эхо-7 — прототип стратегии/RPG на фронтире (Unity 6)

Играбельный прототип по GDD «Эхо-7». Вид и управление как в Diablo 4, модульный sci-fi аванпост в саванне,
волны фауны, которые реагируют на шум, ранги вместо опыта, задачи и поставки Центра, мораль гарнизона,
визиты высоких чинов и экологический цикл планеты. Новичка ведёт пролог из 10 учебных заданий, а интерфейс
выполнен в хайтек-стиле: биомонитор и панель вооружения вместо «шаров» здоровья и маны.

**Весь контент собирается кодом.** Ландшафт, модели построек и существ, материалы, звуки, эффекты и интерфейс
генерируются при запуске. В проекте нет ни одного импортированного ассета, поэтому он открывается
сразу, а настоящие модели и звуки потом подставляются точечно (см. [ROADMAP](docs/ROADMAP.md)).

> ⚠️ Код написан и **проверен компиляцией** против эталонных сборок UnityEngine. Запустить Unity в среде,
> где он создавался, было нельзя, поэтому при первом Play возможны мелкие ошибки времени выполнения.
> Если что-то упадёт, в консоли Unity будет точная строка — исправить обычно несложно.

## Как запустить

1. Установите **Unity 6** (6000.0 LTS или новее) через Unity Hub.
2. Unity Hub → **Add → Add project from disk** → выберите папку репозитория. Если Hub спросит версию,
   выберите установленную Unity 6.
3. При первом открытии появится диалог «Создать сцену игры?» — нажмите **Создать**.
   Если диалога нет: меню **Эхо-7 → Создать сцену игры**.
4. Нажмите **Play**.

Игра запустится и в пустой или безымянной сцене, а также в `SampleScene`: точка входа `Echo7Entry` создаётся автоматически.

### Если хотите URP
Проект по умолчанию работает на встроенном рендере. Чтобы перейти на URP: установите пакет
*Universal RP*, создайте URP Asset и назначьте его в *Project Settings → Graphics*. `MaterialFactory` сам
определит пайплайн и возьмёт шейдеры `Universal Render Pipeline/Lit`. Можно и наоборот: создать новый проект
из шаблона *Universal 3D* и скопировать в него папку `Assets/Echo7`.

### Сборка (билд)
Материалы создаются из кода через `Shader.Find`, поэтому нужные шейдеры должны попасть в билд.
Перед сборкой выполните **Эхо-7 → Подготовить к сборке (шейдеры)**.

### Ввод
Поддерживаются оба варианта *Active Input Handling*: старый Input Manager и новый Input System
(`InputBridge` выбирает нужный автоматически).

## Управление

| Действие | Клавиши |
|---|---|
| Идти / атаковать / взаимодействовать | ЛКМ (удержание — идти за курсором) |
| Стрелять в точку | ПКМ |
| Прямое движение | WASD |
| Перекат (неуязвимость) | Пробел |
| Взаимодействие с ближайшим объектом | E |
| Граната / боевой дрон / аптечка / подрывной заряд | 1 / 2 / 3 / 4 |
| Строительство / навыки / задачи / гарнизон / карта / справка | B / K / J / G / M / F1 |
| Режим стройки | R — поворот, Q — ярус (земля / второй), ПКМ — отмена, стены и настил тянутся мышью, Shift — несколько построек |
| Осмотр настила и лестницы | Shift+клик (обычный клик — пройти по настилу); перекат через перила — спрыгнуть вниз |
| Зум | колесо мыши |
| Пауза, скорость ×1–×3, сохранение | Esc |
| Закрыть брифинг обучения | Пробел или Esc |
| Сохранить / загрузить | F5 / F9 |
| Отладка | F6 ресурсы, F7 волна, F8 +100 ОР, F10 смена погоды, P визит высокого чина |

Настройки партии (зерно карты, длина суток, сложность, отладка) задаются в инспекторе на компоненте `Echo7Entry`.
Там же поле **«Обучение»**: `Ask` — спрашивать при новой игре (по умолчанию), `Always` — всегда пролог, `Never` — сразу в бой.

## Первые шаги в игре

При новой игре появится выбор: **«Пролог: обучение»** или **«Сразу в бой»**.

**Пролог «Высадка»** — 10 коротких заданий. Их ведёт по связи капитан Левина, инструктор Центра.
Пока идёт пролог, время на планете стоит: волн, бурь, хищников и визитов нет. Интерфейс открывается по частям,
по мере того как появляются нужные механики.

| # | Задание | Что открывается |
|---|---|---|
| 1 | Высадка: дойти до командного модуля | биомонитор, цели, журнал |
| 2 | Связь с Центром: клик по модулю | панель командира (ранг, репутация), часы |
| 3 | Ресурсы планеты: добыть 10 титана | склад, шкалы шума и угрозы |
| 4 | Энергосеть: построить энергоузел | меню стройки, энергобаланс |
| 5 | Периметр: 6 секций стены (протяжкой) | стены, ограждения, ворота |
| 6 | Огневая точка: пулемётный узел | турель |
| 7 | Расчёт: назначить бойца на турель | окно гарнизона |
| 8 | Учебная тревога: отбить стайку грызунов | вооружение, способности, радар |
| 9 | Снабжение: встретить капсулу | все базовые постройки |
| 10 | Первая ночь: время запускается, продержаться до рассвета | весь интерфейс |

- Голубой маркер в мире показывает, куда идти. Если цель за краем экрана, у края появляется стрелка с расстоянием.
  Нужная кнопка, вкладка или постройка в меню подсвечивается пульсирующими скобками.
- Кнопка «Брифинг» в панели цели повторяет инструкции. Пролог можно пропустить в любой момент.
- После пролога (+40 ОР) включаются задачи Центра, а следующая волна даёт 4 минуты передышки.
  Дальше новые механики объясняют карточки **«НОВОЕ»**, когда механика встречается впервые: первая ночь, шумовая волна,
  пекло, износ турелей, перегрызенный кабель, падение морали, новые звания и особые враги.

**«Сразу в бой»** даёт готовую стартовую базу с турелью, участком стены, воротами и энергоузлами. Время идёт сразу.
Задачи Центра слева вверху, первая ночная волна — около 22:00. Карточки-подсказки работают и в этом режиме.

## Баланс

Все цифры (постройки, турели, существа, навыки, задачи Центра, визиты высоких чинов) вынесены в ассеты
ScriptableObject в `Assets/Echo7/Resources/Echo7Balance`. Их правят в инспекторе, без программиста.
Изменения во время Play применяются сразу. Встроенная проверка ловит ошибки: дубли, невыполнимые задачи, шанс выше 100%.
При первом открытии проекта ассеты создаются сами. Если их нет — меню **Эхо-7 → Баланс → Создать или дополнить ассеты**.
Без ассетов игра работает на значениях из кода. Подробно — в [docs/BALANCE.md](docs/BALANCE.md).

## Интерфейс

Хайтек-HUD: голографические панели со скошенными углами, сканлайны, сегментные шкалы, моноширинные индикаторы.

- **Биомонитор** (слева внизу) вместо шара здоровья: целостность костюма, ЭКГ (пульс учащается при ранениях),
  статус «НОРМА / РАНЕН / КРИТИЧНО / ЛИХОРАДКА».
- **Вооружение** (справа внизу) вместо шара маны: боезапас кассетой из 20 ячеек, режим, предупреждение о низком боезапасе.
- **Шестигранные слоты способностей** с перезарядкой и кнопки окон (в центре внизу).
- **Голографический радар** с вращающимся лучом: враги, гарнизон, залежи, маркер обучения.
- Сверху: панель командира (звание, ОР, репутация, навыки), статус-строка (день, время, погода, шум, угроза, волны), склад и журнал связи.

## Что реализовано (по разделам GDD)

**1. Основной цикл**
- Смена дня и ночи: днём разведка, добыча и стройка; ночью гарантированные волны; шум провоцирует внеплановые.
- Прогрессия: задачи Центра → очки ранга → новые чертежи и возможности → орбитальная доставка → космопорт.
- Экспансия: глобальная карта, второй аванпост-рудник, торговля на орбитальной станции, экспедиции челноком.

**2. Ролевая система**
- Ранги Специалист → Лейтенант → Капитан → Майор → Полковник. Каждый ранг открывает возможности, как в GDD.
- Дерево навыков: три ветки по 4 навыка (Инженерия, Тактика, Выживание), каждая с реальными модификаторами в системах игры.

**3. Экономика**
- Поставки Центра капсулами по утрам. Объём зависит от репутации, выполненных KPI и ранга; задержки при низкой репутации.
- Местные ресурсы: титан, кристаллы, кремний. Добываются вручную, дронами-сборщиками или бурами. Есть пещеры, которые открывает подрывной заряд.
- Дилемма кремния: жилые блоки (мораль) против лазеров и конденсаторов (оборона и вода). Расход пайков и воды гарнизоном.

**4. База и оборона**
- Модульные стены сами соединяются в секции. Ограждения, бетонные и титановые стены, ворота.
- Второй ярус (с ранга Лейтенант):
  - настил на стенах и опорных колоннах, консоль на 1 клетку, перила по краям;
  - лестницы — путь гарнизона наверх;
  - турели, сенсоры и энергоузлы на стенах (клавиша Q в режиме стройки): дальность +15%, пехота не достаёт;
  - если опору разрушить, всё сверху обрушится.
- Энергосеть: реактор, энергоузлы, видимые кабели, баланс выработки и потребления.
- Пулемётные узлы, лазерные излучатели, тяжёлые турели, мины (расходуются и требуют перезарядки), сенсоры, генератор щита.
- Шумовой маяк-приманка уводит волны и хищников от базы (механика «фауна как оружие»).
- Гарнизон на постах. Если расчёт погиб, турель переходит в автономный ослабленный режим.
- Строительные дроны возводят, чинят и обслуживают постройки.

**5. Угрозы**
- Фоновая фауна: стада рогачей (мясо даёт пайки) и хищники.
- Волны: ночные, шумовые («неожиданная волна»), всплеск шума после взрыва у пещеры, сценарные.
- Особые юниты:
  - Танк (с ранга Капитан) идёт прямо к реактору.
  - Грызуны портят мелкие постройки и перегрызают кабели.
  - Прыгуны перемахивают ограждения и ломают механизмы, заклинивая ворота.
  - Громилы проламывают стены, плевуны стреляют кислотой.
  - Синтетическая угроза: подрыв пещеры может разбудить завод ИИ, и тогда в волнах появляются синт-стражи,
    устойчивые к пулям и уязвимые к лазерам.
- Экология:
  - Пекло: вода испаряется, саванна выгорает в пустыню.
  - Пылевая буря.
  - Ливни: озёра и луга возвращаются.
  - Миграция насекомых: лихорадка, возможны смерти.

**6. Сюжет и дипломатия**
- Диалоги с вариантами действий: вылечить, подбодрить, выдать, изъять, назначить.
- Визиты инспектора, генерала и куратора. Дилемма снабжения: выдать лучшее, хлам или отказать.
  От выбора зависят репутация, уникальные чертежи, урезанные поставки, а при гибели чина — трибунал и понижение.

**Дополнительно:**
- Мораль: отказ выходить на стены, саботаж, дезертирство с оружием.
- Деградация турелей (износ, заклинивание, особенно в пекло).
- Мораль расчёта влияет на точность турели.
- Сохранение и загрузка.

Ответы на технические вопросы из §7 GDD (архитектура, механика «неожиданной волны», блокировка UI рангами,
нестандартные механики) — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Как добавлять постройки, существ,
задачи и диалоги — в [docs/EXTENDING.md](docs/EXTENDING.md), план развития — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Известные ограничения прототипа

- Графика — процедурные заглушки из примитивов в палитре референсов. Это не финальный арт.
- Интерфейс на IMGUI: быстро собирается кодом, но для релиза его стоит перенести на UI Toolkit.
  Шрифты берутся из ОС (Bahnschrift/Consolas на Windows, иначе запасные варианты). Для единого вида добавьте свой TTF.
- Реплики инструктора пока только текстом, без озвучки.
- Второй ярус — один (земля + ярус на высоте стены). Третьего уровня и крыш нет.
  Враги ходят только по земле: на ярус запрыгивают лишь прыгуны.
- Интерьеры (пещеры, станция) и синтетическая угроза заводов ИИ пока представлены заделами, а не полноценными сценами.
- Баланс выставлен «на глаз». Цифры — в ассетах баланса ([docs/BALANCE.md](docs/BALANCE.md)), общие множители — в `GameConfig`.
